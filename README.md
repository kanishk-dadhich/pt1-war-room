# PT1 War Room

A single-page, searchable command cheat sheet for the **TryHackMe Jr Penetration Tester** path / **PT1 Professional Certification** practical exam.

**Live page:** https://kanishk-dadhich.github.io/pt1-war-room/

## Features
- **Live search** — press `/` and filter every command, flag, port, or binary instantly
- **One-tap copy** on every command (strips inline comments)
- **Color-coded by attack phase** — recon → web → passwords → shells → privesc → AD
- **Light / dark theme** toggle (remembers your choice)
- Works on phone and desktop

## Sections
Exam strategy · Recon & enumeration · Web exploitation · Burp Suite · Password attacks ·
Reverse shells & stabilization · Metasploit · Linux PrivEsc (+ **GTFOBins**) ·
Windows PrivEsc (+ **LOLBAS**) · Pivoting & tunneling · Reference tables · Methodology & reporting.

## Usage
Open `index.html` in any browser, or visit the live page above. No build step, no dependencies —
fonts load from Google Fonts, everything else is inline.

> For authorised security testing, CTFs, and exam revision only.
